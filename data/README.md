# Scientific Datasets & Data Provenance

This directory stores standardized data schemas and research reference assets for the **Quantum-XAI CFTR Precision Gene Therapy & LNP Optimization Platform**.

## 1. LNP Atlas Database
- **Official Portal:** https://lnp-atlas.kisti.re.kr/
- **Dataset DOI:** [10.5281/zenodo.17243733](https://doi.org/10.5281/zenodo.17243733)
- **Primary Release File:** `LNP_Atlas_DB_202509_v1.csv`
- **Fields:** 28 standardized physicochemical and bioactivity parameters.
- **Formulation Count:** ~1,092 experimental entries.

## 2. NCBI ClinVar CFTR Variants
- **Accession:** Gene ID 1080 (CFTR, 7q31.2)
- **Coverage:** Common CFTR mutations (F508del, G542X, G551D, R117H, N1303K, W1282X) and benign polymorphic controls (M470V, F508C).

## 3. NCBI GEO GSE15568 Transcriptomics
- **Accession:** GSE15568 (Affymetrix Human Genome U133 Plus 2.0)
- **Cohorts:** Primary human bronchial epithelial cells homozygous for CFTR F508del (n=12) vs healthy donors (n=12).
- **Target Pathways:** Reactome R-HSA-382551 (Inorganic ion transport), R-HSA-381119 (Unfolded Protein Response), R-HSA-6785807 (IL-4/IL-13 mucociliary signaling).

## 4. Cryo-EM CFTR Protein Structure
- **PDB Accession:** 5UAK (3.9 Å resolution)
- **Reference:** Liu F, et al. *Cell* 2017.
