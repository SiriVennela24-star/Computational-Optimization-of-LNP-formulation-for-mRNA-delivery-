# Contributing to Quantum-XAI CFTR Platform

We welcome computational biology researchers, medicinal chemists, quantum computing researchers, and machine learning engineers to contribute.

## Guidelines
1. **Scientific Integrity**: All datasets imported must maintain provenance (DOIs, sample accessions, PubMed IDs). Never fabricate experimental measurements.
2. **Quantum Transparency**: State clearly when an execution is performed on an educational statevector simulator vs physical quantum processing units.
3. **Clinical Boundaries**: Always preserve non-clinical disclaimers; predictions are computational hypotheses.
4. **Code Quality**: Ensure all TypeScript types pass (`pnpm run build`) and test suites succeed (`pnpm test`).
